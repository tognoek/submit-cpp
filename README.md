Online Judge… nhưng chạy **trên máy bạn**.  
Không cloud, không chờ chấm, không “mất mạng là mất bài”. 🏠

Kéo gói test vào → viết C++ → bấm **Chấm bài**.  
`AC` 🟢 / `WA` 🔴 / `TLE` ⏰ / `RE` 💥 — cảm giác Codeforces, vị nhà làm.

> 🤖 Xây bằng AI từ đầu đến cuối. Có bug? Chắc AI cũng đỏ mặt. 😳

---

## ✨ Nó làm được gì?

- 📦 **Kéo thả là có bài** — Themis folder / ZIP, một bài hoặc cả “cặp” `BAI1` `BAI2`…
- ⌨️ **Editor không giả trân** — C++, minimap, Ctrl+Z/Y, chạy thử trước khi nộp
- 🏁 **Chấm kiểu đấu trường** — AC / WA / TLE / RE, soi từng test như Codeforces
- 📜 **Nhật ký tội lỗi** — lịch sử nộp, xem lại code cũ, xuất ZIP mang đi
- 🌙 **Đêm AC / ngày debug** — theme sáng tối, tùy mood
- 🧳 **Portable** — đóng gói một phát, máy khác mở là chấm (không cần cài Node)

---

## 🏃 Chạy

Cần Node **22.5+**. Rồi:

```bash
npm install    # 📥
npm run setup  # 🛠️ g++ portable
npm run dev    # 🔥
```

Đơn giản thế thôi — xong, không được kêu AI nhé. 🎉

Muốn mang máy khác: `npm run package` → thư mục `portable/` → **Judge.exe**. 🧳✨

### 🎭 Cảm xúc khi chấm (không cần bảng)

**AC** 🥳  
Đứng dậy. Vỗ đùi. Screenshot gửi group. Gọi là *skill issue của đề*. Đi ngủ như người thắng cuộc (dù mới 1 bài).

**WA** 🥲  
Sample xanh lè. Test thật đỏ như máu. Bạn mở output, nhìn 3 giây, thì thầm: *“…à.”* Rồi mở lại code như chưa từng tự tin.

**TLE** 🐢  
`n = 1e5`. Bạn vẫn `for` trong `for`. Judge đếm từng mili giây. Bạn đếm từng giọt nước mắt. *“Tối ưu sau”* = không bao giờ.

**RE** 💥  
Segmentation fault. Không phải bug — là *lifestyle*. `a[-1]`, `nullptr`, `vector` trống… cả nhà cùng nổ.

**CE** 🧱  
Compiler: *“expected ';' before …”*  
Bạn: *“…”*  
Cả phòng lab hiểu. Không ai nói gì. Chỉ có tiếng thở dài.

**PE** 🙈  
Đáp án đúng. Dấu cách sai. Xuống dòng thừa. Judge lạnh như người yêu cũ — đúng rồi vẫn không cho qua.
